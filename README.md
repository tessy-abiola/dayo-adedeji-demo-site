# Dayo Adedeji personal site

Static site. Open `index.html` in a browser, or upload the folder to any static host. No build step or dependencies.

## Editing
All content is in the `content` object near the bottom of `index.html`. Colours are CSS variables at the top (`:root`). Images are listed in the `IMGS` object and live in `assets/images/`.

## Before launch
- Replace screenshot-based images with original, permitted photography (most are about 680px wide and will look soft on high-density screens).
- Confirm reuse rights for every image (publisher, photographer and Instagram/LinkedIn sources).
- Add the Dynasty Africa URL, email and social links in `content`.
- Add source links to Recognition (Forbes, Cannes).
- Fill in the Moni entry, confirm its role and add campaign visuals.
- `dayo-cream-suit-portrait.webp` is currently unused.
- Media section is hidden until `content.media` has entries.
